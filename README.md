## 🛠️ Tech Stack & Features

* **Frontend:** Single-file HTML5 structure utilizing Tailwind CSS CDN for modern responsive layouts.
* **Typography:** Google Fonts (**Plus Jakarta Sans** for English, **Cairo** for Arabic, and **JetBrains Mono** for numbers/code).
* **Icons:** Font Awesome 6.5.1 CDN.
* **Interactive Animations:**
  * **350vh Pinned Scroll Engine:** Calculates scroll progress (`0.0` to `1.0`) to drive a 3D zoom-in entrance (`scale(0.35)` to `scale(2.5)`).
  * **360° Rotating Photo Frame:** Continuous 360-degree spinning dashed orbit ring (`.photo-360-orbit`) with floating tilt animation (`floatUpDown`) and glowing red frame.
  * **Scroll Reveal:** Intersection Observer engine (`.reveal.active`) animating sections on scroll down.
* **Localization:** Vanilla JavaScript bilingual switcher (`🌐 العربية / English`) supporting full RTL direction adjustment (`dir="rtl"`).
* **Hosting:** Deployed via **GitHub Pages**.
